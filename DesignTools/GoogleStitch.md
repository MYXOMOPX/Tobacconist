# Дизайн Mini App через Google Stitch

Google Stitch (stitch.withgoogle.com) — генератор UI-экранов по текстовому
промпту (можно и по картинке-референсу). Работает по-другому, чем Claude:
не диалог, а проект из отдельных экранов, каждый генерируется по одному
плотному текстовому промпту, без markdown-разметки внутри поля ввода —
пиши промпты как один абзац сплошным текстом (списки/жирный шрифт в
самом поле Stitch не воспринимает как форматирование).

Источник требований — актуальная спека:
`docs/superpowers/specs/2026-08-25-tobacconist-group-buy-design.md`.
Демо-данные (барыги, бренды, вкусы, участники, примеры заказов на все
статусы) вынесены в `DesignTools/sample-data.json` — тот же файл
переиспользуют промпты для Claude и OpenDesign, чтобы на всех макетах
были одни и те же имена и цифры.

## Как это сделать в интерфейсе Stitch (по шагам)

У Stitch нет отдельного поля "системный промпт", которое действует на
весь проект сразу (в отличие от Claude) — контекст нужно физически
вставить вместе с промптом первого экрана. Дальше Stitch держит стиль
внутри проекта сам, и в следующих промптах достаточно фразы "в том же
стиле, что и предыдущие экраны" (она уже есть во всех промптах ниже).

Простой путь (стартовый экран Stitch, без кнопки "Создайте проект"):
1. На стартовом экране кликни переключатель **"Приложение"** (не
   "Веб-интерфейс") — это режим генерации под мобильный экран, что и
   нужно для Telegram Mini App.
2. Кликни в большое текстовое поле и вставь туда **весь промпт целиком**
   из раздела **"Один промпт на все экраны"** ниже — он одним куском
   задаёт стиль и просит все экраны сразу.
3. Модель слева от стрелки отправки можно оставить по умолчанию.
4. Нажми стрелку **↑** справа — это создаст новый проект и сразу
   сгенерирует первый экран.
5. Внутри созданного проекта появится такое же поле ввода — туда по
   одному вставляй остальные промпты из этого файла, каждый отдельным
   сообщением.

Альтернативный, более точный путь (кнопка **"Создайте проект"** вверху
справа, модалка с полями DESIGN.md/файлы/сайт/"Дополнительные
инструкции"): в этой же папке уже есть готовый файл `DESIGN.md`,
заполненный по этому же формату (акцент `#F05E23`, палитра статусов,
типографика, компоненты) — вставь его содержимое целиком в первое поле
**"Вставить существующий файл DESIGN.md"** (или перетащи сам файл в
блок "Загрузить файл DESIGN.md"), поле "Дополнительные инструкции"
можно оставить пустым или продублировать туда пару ключевых
ограничений (Telegram Mini App, мобильный вьюпорт), остальные поля
(файлы/GitHub/сайт) не нужны — жми **"Продолжить"**. Этот путь
надёжнее, чем ручной пересказ контекста в свободном поле ниже, потому
что `DESIGN.md` — тот самый формат, который Stitch ожидает нативно.

## Один промпт на все экраны

Это одно сообщение, которое просит Stitch сгенерировать сразу весь
набор экранов проекта — а не по одному, как раньше. Внутри —
одинаковые данные (барыги/бренды/вкусы/участники) и одинаковое
описание таб-бара для каждого экрана, поэтому экраны должны получиться
согласованными между собой: одна и та же навигация, одни и те же
имена и цифры, а не случайный плейсхолдер-текст на каждом скрине.
Если Stitch за один раз сгенерирует не все экраны, а меньше — отправь
следующим сообщением "продолжи, сгенерируй оставшиеся экраны из
списка выше" (сам список экранов уже есть в этом промпте, он его
запомнит по проекту).

```
Спроектируй полный набор экранов мобильного Telegram Mini App для
групповой закупки табака среди друзей — организатор открывает заказ у
конкретного продавца, участники закрытой группы добавляют себе позиции
(бренд, вкус, граммовка, количество), дальше идёт сверка поставки и
отметки оплаты. Экран открывается внутри Telegram на телефоне, ширина
около 375-430px, верхнюю системную шапку с кнопкой назад рисует сам
Telegram — в макете её не показывай, но оставляй отступ сверху. Стиль:
фиксированная тёмная тема, не подстраивается под системную тему
телефона — угольно-чёрный фон экрана, чуть более светлые тёмно-серые
карточки поверх него, ещё более светлые приподнятые элементы вроде
всплывающих панелей снизу, без теней и градиентов. Фирменный акцентный
цвет для всех кнопок, активной вкладки навигации и главных положительных
сумм — тёплый оранжевый #F05E23. Все денежные суммы, вес в кг и
количества набирай моноширинным шрифтом с табличными цифрами, это
должно визуально отличаться от обычного текста названий. Статус
заказа показывай бейджем-таблеткой: "Сбор заказов" — зелёная заливка,
"На сверке" — жёлтая заливка, "Завершён" — серый аутлайн (только
обводка), "Отменён" — красный аутлайн; заливка для активных статусов,
аутлайн для терминальных. Минимальная кликабельная область — крупная,
под палец. Текст интерфейса на русском языке.

На каждом экране, где это уместно, повторяй один и тот же нижний
таб-бар — он должен выглядеть идентично на всех экранах, где
присутствует: текстовые вкладки без иконок на тёмной поверхности,
активная вкладка подчёркнута снизу оранжевой линией. Для обычного
участника таб-бар из двух вкладок: "Заказы" и "История". Для экранов
администратора таб-бар из трёх вкладок: "Заказы", "Барыги", "История".
Модальные экраны и чек-лист сверки показывай без таб-бара, как
отдельный полноэкранный поток поверх него.

Используй везде одни и те же демо-данные, не придумывай новые имена
на разных экранах. Барыги (продавцы): Darian Shisha, Boss Shisha,
World Hookah Market, БарыгаПафос. Бренды табака и их вкусы: DarkSide —
Needls, Desert Eagle, Killer Milk, Ice Storm, Blood Orange, Wild Fire;
MustHave — Milky Rice, Kiwi Smoothie, Watermelon, Peach Tea, Mango
Lassi, Strawberry Cream; BlackBurn — Green Tea, Lemon Mint, Black
Grape, Cherry Cola, Ice Mango, Blueberry Muffin; Tangiers — Cane Mint,
Frappe Latte, Kashmir Peach, Horchata, Cactus Cooler, Noir. Граммовки
только 100г и 250г. Участники группы: Ты (админ, текущий пользователь),
Кирилл, Ваня, Тимур, Женя.

Сгенерируй следующие экраны одним набором, каждый как отдельный
артборд. Экран 1, список активных заказов участника: карточки заказов
у Darian Shisha (статус "Сбор заказов", зелёный) и у Boss Shisha
(статус "На сверке", жёлтый), в карточке Darian Shisha — "у тебя 2
позиции, 1.25 кг, 49.50 €", в карточке Boss Shisha — "у тебя 1
позиция, 0.25 кг, 10.00 €", таб-бар "Заказы" активен. Экран 1б, тот
же экран заказов в состоянии загрузки: вместо карточек — 3
прямоугольных skeleton-плейсхолдера с мягким пульсирующим свечением на
тёмной поверхности, повторяющих форму обычной карточки заказа. Экран
2, заказ у Darian Shisha в статусе "Сбор заказов": ассортимент по
брендам DarkSide, MustHave, BlackBurn, Tangiers из списка выше
(у DarkSide вкус Wild Fire показан недоступным — перечёркнутый чип),
у каждого вкуса переключатель граммовки 100г/250г и степпер
количества, внизу прилипающая панель "Твой заказ: 2 позиции, 1.25 кг,
49.50 €". Экран 2б, тот же экран заказа в состоянии загрузки
ассортимента: заголовок и таб-бар уже отрисованы, а на месте карточек
брендов — вертикальный стек из 4-5 skeleton-полосок разной ширины с
пульсацией. Экран 3, заказ у Boss Shisha в статусе "На сверке":
баннер "Добавление позиций закрыто, идёт сверка с продавцом", список
своей одной позиции DarkSide Desert Eagle 250г x1, 10.00 €, без
возможности редактирования. Экран 4, "Мой заказ" — детальная сводка
по заказу Darian Shisha: позиции Needls 250г x2 21.00 €, Kiwi Smoothie
250г x3 28.50 €, итого 1.25 кг и 49.50 €, бейдж оплаты "Не оплачено"
серым аутлайном, статус-бейдж "Сбор заказов" внизу. Экран 5, история
заказов участника: карточка World Hookah Market со статусом "Завершён"
(серый аутлайн) и карточка Darian Shisha со статусом "Отменён"
(красный аутлайн), обе без действия "заказать". Экран 6, для админа —
bottom-sheet "Новый заказ": заголовок "У кого закупаемся?", список из
четырёх барыг (Darian Shisha и Boss Shisha неактивны с подписью "уже
есть активный заказ" и своим статус-бейджем рядом, World Hookah Market
и БарыгаПафос доступны), внизу кнопка "Начать заказ". Экран 7, сводный
экран заказа для админа по Boss Shisha в статусе "На сверке": позиции
агрегированы по всем участникам — Desert Eagle 250г x1 10.00 €, Cane
Mint 100г x3 13.20 € (подпись "добавлено администратором"), Needls
250г x2 20.00 €, итого 1.05 кг и 43.20 €, ряд кнопок "Завершить заказ"
(заливка), "Вернуть в работу" и "Чек-лист сверки" (на поверхности,
без заливки), "Отменить заказ" (красный аутлайн), ниже блок "Слепок
для барыги" моноширинным текстом на затемнённой подложке с кнопками
"Скопировать текст" и "Выгрузить файл". Экран 8, модалка "Добавить
позицию участнику" (доступна только в статусе "На сверке"): выбор
участника из списка Кирилл/Ваня/Тимур/Женя, затем выбор бренда MustHave,
вкуса Kiwi Smoothie, граммовки 250г и степпер количества, кнопка
"Добавить". Экран 9, чек-лист сверки поставки по заказу Boss Shisha:
прогресс "Принято 5 из 6", три позиции — Desert Eagle 250г нужно 1
привезли 1, Needls 250г нужно 2 привезли 1 (недовоз, тонкий жёлтый
акцент слева), Cane Mint 100г нужно 3 привезли 3, кнопка "Завершить
сверку" заливкой внизу. Экран 10, итог сверки и оплаты по этому же

ниже список участников с чекбоксами оплаты — Ты и Кирилл отмечены

обычным образом, не скелетоном.
```

## Системный контекст (вставлять вместе с промптом первого экрана)

Вынесен в отдельный файл `DesignTools/stitch-system-context.txt` —
открой его и скопируй содержимое целиком (уже единым абзацем, без
markdown-разметки, как любит Stitch).

## Промпты по экранам (запасной вариант — по одному)

Используй это только если единый промпт выше не зашёл (Stitch
сгенерировал мало экранов, перепутал стиль, отказался обработать
такой длинный текст) — тогда собери экраны так же, как раньше, по
одному промпту за раз. Первый ("Список активных заказов") вставляется
вместе с блоком "Системный контекст" ниже — он же задаёт стиль всего
проекта, остальные идут каждый отдельным сообщением уже без контекста,
только с самим промптом.

**Список активных заказов:**
```
Мобильный экран Telegram Mini App. Список активных заказов у разных
продавцов. Каждый заказ — карточка со скруглёнными углами: название
продавца жирным, справа цветной бейдж статуса, под названием —
количество позиций пользователя в заказе и сумма в евро, либо подпись
"Ты ещё не заказывал", если пусто. Вверху экрана — заголовок раздела
"Активные заказы".
```

**Экран заказа, статус "Сбор заказов" (добавление позиций):**
```
Мобильный экран Telegram Mini App в том же стиле, что и список
заказов: детальный экран одного заказа у продавца "DarkSide Shop",
статус-бейдж "Сбор заказов" (зелёный) рядом с названием вверху. Ниже —
список ассортимента, сгруппированный заголовками по брендам, внутри
каждого бренда — карточки вкусов: название вкуса, под ним два маленьких
переключаемых чипа граммовки "100г" и "250г", справа степпер количества
с кнопками минус и плюс и числом между ними моноширинным шрифтом.
Внизу экрана — прилипающая широкая кнопка-панель с текстом "Мой заказ:
3 позиции, 0.75 кг, 24.50 €" (вес и сумма — моноширинным шрифтом) и
стрелкой перехода.

количество, сумма строки) без кнопок редактирования, одна из строк

**Своя сводка по заказу:**
```

## Как итерировать внутри Stitch

- Правь экран точечными текстовыми правками ("сделай бейдж статуса
  крупнее", "подвинь итоговую сумму выше кнопки") вместо полной
  перегенерации — так стиль не расползается между экранами одного
  проекта.
- Если новый экран визуально "не попадает" в стиль остальных — в
  промпте явно напиши "в том же стиле, что и предыдущие экраны этого
  проекта" (как сделано в промптах выше).
- Генерируй 2–3 варианта на самые важные экраны (список заказов и
  экран заказа с добавлением позиций) — это самые часто используемые
  экраны, имеет смысл выбрать из нескольких вариантов.

## Ограничения, которые нужно держать в голове

- Stitch — генератор концепта/раскладки, а не точного пиксель-перфект
  макета: не полагайся на точные отступы/шрифты из результата, бери
  общую компоновку, иерархию и цветовую систему.
- Итоговый экспорт лучше делать в Figma (Stitch это умеет) — дальше уже
  оттуда снимать точные значения (цвета, отступы, размеры шрифтов) для
  реальной вёрстки, а не копировать сгенерированный код напрямую в
  прод.
- Консистентность между экранами в Stitch слабее, чем в едином
  HTML/CSS-артефакте Claude — если после генерации всех экранов стиль
  всё равно разъехался, финальную сверку и "причёсывание" в единую
  палитру/типографику стоит сделать вручную в Figma перед передачей на
  фронт.
