Контекст для всех экранов проекта: Telegram Mini App для групповой
закупки табака среди друзей. Организатор (админ) открывает заказ у
конкретного продавца, участники закрытой группы Telegram добавляют
себе позиции (бренд, вкус, граммовка, количество), дальше идёт сверка
поставки и отметки оплаты. Экран открывается внутри Telegram на
телефоне, ширина около 375-430px, весь экран занят содержимым (верхнюю
системную шапку с кнопкой назад рисует сам Telegram, в макете её не
показывай, но оставляй отступ сверху). Главное действие каждого экрана
оформляй широкой кнопкой на всю ширину внизу экрана (аналог Telegram
MainButton). Минимальная кликабельная область элементов — крупная,
под палец, без мелких иконок-ссылок. Внизу экрана — постоянный
таб-бар с текстовыми вкладками без иконок, активная вкладка
подчёркнута снизу акцентным цветом.

Фиксированная тёмная тема на всё приложение (не подстраивается под
системную тему телефона): угольно-чёрный фон экрана, чуть более
светлые тёмно-серые карточки поверх него, ещё более светлые
приподнятые элементы вроде всплывающих панелей снизу — без теней,
глубина через ступени яркости тёмного. Фирменный акцентный цвет для
всех кнопок и активных элементов — тёплый оранжевый #F05E23
(ember-стилистика, тлеющие угли на угольно-чёрном фоне), используй его
последовательно на всех экранах. Все денежные суммы, вес в кг и
количества набирай моноширинным шрифтом с табличными цифрами (как в
показаниях приборной панели) — это должно визуально отличаться от
обычного текста названий и подписей.

Статус заказа всегда показывай цветным бейджем-таблеткой по одной и
той же системе цветов на всех экранах, эта палитра отдельная от
акцентного оранжевого, чтобы бейдж и обычная кнопка не путались:
статус "Сбор заказов" — зелёная заливка, "На сверке" — жёлтая заливка
(не оранжевая), "Завершён" — серый аутлайн (только обводка, без
заливки), "Отменён" — красный аутлайн. Заливка — для активных
статусов, аутлайн — для терминальных/архивных. Крупный дружелюбный
шрифт без засечек для обычного текста, достаточные отступы между
карточками. Текст интерфейса — на русском языке.
